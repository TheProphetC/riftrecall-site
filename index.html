The first Mac milestone

Useful history, with honest boundaries.

The aim is to make each player’s own available match history easier to revisit, while being clear about what was imported and what remains unknown.

01 / PERSONAL

Your own completed matches

Start with the signed-in player’s identity and completed-match history, if a permitted and available local data path can be established.

02 / LOCAL

Records stay on the Mac

The planned first release stores match records locally and separates them by account and region.

03 / CONTEXT

Encounters from imported history

Count repeat teammates and opponents only across matches already imported. Unknown identities stay unknown; history coverage is not lifetime coverage.

Competitive integrity

Built around completed games.

RiftRecall’s first milestone is limited to the player’s own account and completed matches. It is not a lobby scouting tool, and it will not try to uncover information League deliberately hides.

  • ✓No champion-select identity scouting or anonymity bypass.
  • ✓No protected process-memory access or gameplay automation.
  • ✓No gameplay writes; client credentials are not part of match records.
  • ✓No backend or remote account service is planned for the first milestone.

Where the prototype stands

The native macOS app has sample-backed Matches and Encounters screens plus a local storage and encounter-calculation foundation. The League connection and real-game import are still pending policy guidance and live validation.
